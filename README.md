Berry High is a 2 two player 2D platformer demo made using Godot engine. The goal is to reach the top and reunite the berry players.

Controls:
  Player 1 (arrow keys): 
  Right arrow key: Move right
  Left arrow key: Move left
  Up arrow key: Jump
  Right CTRL: Dash
  
Player 2 (WAD): 
  A: Move right
  D: Move left
  W Jump
  Left CTRL: Dash
